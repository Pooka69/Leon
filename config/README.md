# Leon Configuration

This directory contains configuration files for Leon personal assistant.

## config.json

You can create a `config.json` file in this directory to customize Leon's behavior:

```json
{
  "assistant_name": "Leon",
  "language": "en",
  "voice_enabled": false,
  "weather_api_key": "",
  "timezone": "UTC"
}
```

### Configuration Options

- **assistant_name**: The name of your assistant (default: "Leon")
- **language**: Language code (default: "en")
- **voice_enabled**: Enable voice interaction (default: false)
- **weather_api_key**: API key for weather services
- **timezone**: Your timezone (default: "UTC")
